# Hamza Amiri — Portfolio

Personal portfolio at [hamzaamiri.dev](https://hamzaamiri.dev), in English (`/en`) and French (`/fr`).

Built with Next.js 16, React 19, Tailwind CSS 4 and Framer Motion.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Edit the content

All text lives in `src/content/en.ts` and `src/content/fr.ts`; contact details and media paths in `src/content/site.ts`.
Images, videos and CVs are in `public/`.
